# Система учета клиентов и продаж для малого бизнеса

Учебный проект производственной практики в Академии ИМСИТ.

## Запуск

Установите Python 3.11 или новее. В папке проекта выполните:

```sh
python -m venv .venv
python -m pip install -r requirements.txt
python app.py
```

В Windows перед установкой зависимостей активируйте среду командой `.venv\Scripts\activate`; в Linux/macOS — `source .venv/bin/activate`.
При первом запуске задайте собственный пароль администратора длиной не менее 10 символов. Логин: `admin`. Откройте http://127.0.0.1:5000.

## Возможности

- Регистрация клиентов и поиск по имени или телефону.
- Каталог товаров с ценой в копейках.
- Продажа одного вида товара за операцию; модель данных допускает несколько позиций.
- История продаж, отмена администратором, исключение отмененных сумм из выручки.
- Отчет по диапазону дат UTC и экспорт CSV.
- Роли администратора и менеджера, хеширование паролей, защита POST-запросов CSRF.

## Проверка

```sh
python -m unittest -v
```

10 автоматизированных проверок используют временную базу и не затрагивают рабочие данные.

## Хранение и ограничения

SQLite создает `sales.db` в текущей папке. Для резервной копии остановите приложение и скопируйте базу в защищенную папку. Не публикуйте базу, пароли и ключ APP_SECRET. Переменная APP_DB меняет путь к базе; APP_SECRET задает постоянный секрет сеансов. Без APP_SECRET перезапуск завершает существующие сеансы.

Это локальный учебный прототип: встроенный сервер Flask не предназначен для публичного размещения. Для промышленной эксплуатации требуются WSGI-сервер, HTTPS, ограничение попыток входа, аудит действий, регламент резервирования и проверка обработки персональных данных. Складские остатки, платежные интеграции и фискальные документы не реализованы. Удаление и редактирование справочников в интерфейс не включены, чтобы не менять историю операций.
